# 🛡️ StatBench360 V71126v10

> **Sistema Avanzado de Gestión de Banquillo, Estadísticas y Actas Oficiales para Fútbol Base 11**

---

## 📋 Descripción del Proyecto

**StatBench360** es una aplicación web progresiva y ligera (diseñada con arquitectura de archivo único en HTML5, Tailwind CSS y JavaScript vainilla) optimizada para entrenadores, cuerpos técnicos y delegados. Permite llevar el control absoluto en directo de un partido de fútbol base (minutaje, sustituciones, goles, asistencias y tarjetas), con persistencia de datos local y la capacidad de generar y compartir actas oficiales en PDF adaptadas a la normativa federativa.

---

## ✨ Características Principales

* 📊 **Configuración Previa Completa:** 
  * Definición de condición de local o visitante, nombre de equipos, jornada, fecha y **liga / competición** (reflejada formalmente en el acta oficial).
  * Control y gestión de plantillas amplias con selección múltiple y borrado masivo.
  * Carga automática de plantillas mediante **ficheros externos (.txt / .csv)** o escaneo de imágenes mediante **OCR (Tesseract.js)**.
* ⏱️ **Control de Partido en Directo:**
  * Cronómetro integrado con gestión de 1ª parte, descanso (con cuenta atrás propia) y 2ª parte.
  * Alertas de voz automatizadas configurables por intervalos o mediante alarmas de minutos exactos.
  * Registro cruzado de goles, asistencias con validación lógica, tarjetas (amarillas, doble amarilla y rojas) y control estricto de ventanas de sustitución (máximo 3 por equipo, excluyendo el descanso).
* 📜 **Historial y Persistencia Inteligente:**
  * Permite volver a consultar y revisar los datos, cronología y estadísticas de un **partido ya finalizado** siempre que no se hayan reseteado los valores o iniciado un nuevo encuentro.
  * Botón de reseteo rápido en la pantalla de configuración inicial para vaciar y limpiar el marcador o convocatorias anteriores.
* 📄 **Actas Oficiales y Exportación:**
  * Generación automática de actas en **PDF** con nomenclatura exacta: `Acta_[Jornada]_[Fecha]_[Equipo_Local]_vs_[Equipo_Rival].pdf`.
  * Integración nativa para compartir el acta por **WhatsApp** o exportar estadísticas detalladas de jugadores y rivales en formato **CSV / Google Sheet**.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3** con diseño responsivo móvil-primero (*mobile-first*).
* **Tailwind CSS** para un diseño visual moderno y adaptado a los colores corporativos de SD La Salle.
* **FontAwesome** para la iconografía dinámica.
* **jsPDF** para la estructuración y descarga de documentos oficiales en PDF.
* **Tesseract.js** para la digitalización mediante OCR de convocatorias en imagen.

---

## 🚀 Uso Rápido

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` directamente en cualquier navegador web moderno (móvil, tablet o PC).
3. Configura los datos de tu equipo, carga la convocatoria y arranca el partido.
